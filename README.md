# UX-portfolio

UX- ja e-kaubandussüsteemide disainer (ERP + frontend + turundus)

Ma ühendan UX disaini, e-kaubanduse süsteemid ja turundusvisuaalid, et parandada veebipoodide müügitulemusi.

# E-kaubanduse ja ERP-integratsiooni kogemus
### Olen töötanud e-kaubanduse lahendustega, kus olen:
- toetanud ERP-integratsiooni protsesse
- aidanud ühendada frontendi funktsionaalsust backend-süsteemidega
- panustanud toodete ja andmete liikumise parandamisse süsteemide vahel
### Mida olen sellest õppinud:
- kuidas e-kaubandussüsteemid tegelikult toimivad kasutajaliidese taga
- kuidas tehnilised piirangud mõjutavad UX-otsuseid
- kui oluline on andmete liikumine kasutajakogemuse jaoks

# Projektid
## Projekt 1: E-kaubanduse + ERP integratsioon
### Mida tegid:
- töötasin e-poe ja ERP ühendustega
- aitasid arendada frontend funktsionaalsust 
### Mida õppisid:
- kuidas andmed liiguvad süsteemide vahel
- kuidas UX sõltub tehnilistest piirangutest
- kuidas e-kaubanduse protsess töötab päriselt
  
## Projekt 2: UX / kasutajaliidese töö
### Mida tegid:
- parandasid kasutajavooge
- tegid lihtsama ja selgema UI lahenduse
### Mida õppisid:
- kuidas kasutaja käitub veebis
- kuidas disain mõjutab konversiooni
- kuidas teha lihtsust, mis müüb

## Projekt 3: Bännerid ja turundusvisuaalid
### Mida tegid:
- tegid Meta ja e-poe bännereid
- lõid kampaania visuaale
### Mida õppisid:
- mis visuaalid müüvad paremini
- kuidas sihtrühm mõjutab disaini
- kuidas ühendada disain ja turundus

# Oskused
### Disain
- Figma (UI, UX, FigJam)
- Adobe’i tööriistad
- Canva
### E-kaubandus ja süsteemid
- ERP-töövood

- koostöö frontend-tiimidega
### Turundus
- Meta Ads reklaamiloovlahendused
- kampaaniavisuaalid
- sotsiaalmeedia sisu disain

# Olen õppinud
- UX ja e-kaubanduse loogikat
- ERP ja frontend süsteemide tööpõhimõtteid
- visuaalse turunduse tegemist
- kuidas disain mõjutab müüki
- kuidas töötada arendus- ja turundusmeeskondade vahel

# Mida ma otsin
### Otsin rolli, kus saan:
- töötada e-kaubanduse toodete ja lahendustega
- parandada kasutajakogemust ja konversiooni
- luua müüki toetavaid turundusvisuaale
- teha koostööd arendus- ja turundustiimidega
