# UX-portfolio

UX- ja e-kaubandussüsteemide disainer (ERP + frontend + turundus)

Ma kujundan e-kaubanduse kogemusi, mis ühendavad UX-i, turundusvisuaalid ja süsteemiloogika (ERP + frontend). Keskendun konversioonide ja kasutajavoogude parandamisele nii disaini kui ka tehnilise mõistmise kaudu.

- ERP-i ja veebipoe integratsiooni UX
